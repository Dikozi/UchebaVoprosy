# Отдел B «Дизайн и технология» · единая версия v2

Пометка «смоук»: проверка на Диске заказчика до заморозки.

## 1. Концепция

Телефонный HUD на тёмном фоне: вкладка месяца 350px без горизонтального скролла, дни строками, восемь квадратов привычек в строке, «сегодня» в одном флике, и каждое касание сразу меняет цифру в закреплённой шапке. Вся графика живёт в ячейках (SPARKLINE, цветовая шкала, эмодзи, крупное число); встроенных диаграмм ноль. Технически это один генератор: ядро формул на скрытой ленте «Расчёт» на весь год, видимые листы только вводят и показывают, Excel-бонус собирается тем же кодом через адаптер из пяти швов.

## 2. Структура файла и движок

Вкладки: «Старт», «Янв»…«Дек» (три буквы, цвет по сезону), «Год»; скрытые «Расчёт» и «Списки» (списки, уровни, опции SPARKLINE, gid).

- «Старт», один столбец ≤340px: год, инструкция, восемь строк 40px «иконка, название, цель дней в месяц», ссылка «Сегодня →», поле «считать сегодняшним днём».
- Месяц: отметки B:I (булевы ячейки + проверка «список TRUE,FALSE» → флажки), сон K, энергия L, настроение M, дневник N в строке дня; под сеткой три цели месяца и итоги. Скрытых колонок нет.
- «Расчёт»: лента строк 5…370, строка = день года: A дата, B месяц, C старт недели, D «день прошёл», F:M пропуски месяца, P:W серии, Z итог дня, AA идеальный, AB XP. Отметки приходят зеркалом `=IFERROR('Сен'!B26=TRUE;FALSE)`; удаление строки на месяце стоит один день, не каскад #REF!. Видимые листы считают только `=IFERROR(Расчёт!X;"")` и один COUNTIF по своей строке.

Год фиксируется при сборке (`--year`): строки недель статичны, февраль правильной длины. Единственный TODAY() в `Расчёт!B1` с ручным переопределением со «Старта»; копия в J1:K1 каждого месяца для УФ, которое не видит другие листы.

Импорт: ничего из списка риска (полосы данных, объекты, форматы с эмодзи, литералы массивов, OFFSET, INDIRECT, ARRAYFORMULA, MAXIFS). Мастер доводится один раз из Python через Sheets API (инструмент сборки, скриптов в файле нет): локаль ru_RU, часовой пояс, BOOLEAN-валидация, защита `warningOnly` всего кроме ввода, gid в «Списки». Покупатель копирует готовую Таблицу; ссылка «Сегодня →»: бонус после смоука gid.

Excel-бонус: тот же генератор, `ExcelTarget` с пятью швами: нативный флажок, полоса данных вместо SPARKLINE, ссылки `internal:`, защита xlsx с открытыми полями ввода, кэш значений через LibreOffice.

## 4. Визуальная система

Тема: тёмный файл основной, светлый: второй файл тем же генератором, переключателя внутри нет. Тёмная тема приложения: проектируем под выключенную, каждый смысл кодируется дважды (заливка + глиф или текст), матрица 2 ОС × 3 режима до заморозки палитры; если приложение ломает панели, основным становится светлый файл одним флагом.

Палитра, тёмная/светлая: фон #0E1016/#F4F5F9; панель #1B1F2A/#FFFFFF; панель-2 #262B38/#EEF0F5; текст #F2F4F8/#14171F; приглушённый #A0A7B8/#5C6478; акцент «сегодня» #F6C453/#F5B800; «сделано» заливка #22A35E/#BBF7D0, глиф #06301A/#14532D; строка «сегодня» #3A3115/#FFF3C4; игровой фиолетовый #8B5CF6/#7C3AED; шкала карты года #262B38→#166534→#22A35E (светлая #EEF0F5→#86EFAC→#16A34A). Красного и розового нет ни в одном правиле; сферы удалены.

Семантика: зелёный: сделано и прогресс; янтарный: только «сегодня»; фиолетовый: только игра; серый: остальное; пропуск: пустой квадрат без крестов; выходной: приглушённая подпись даты.

Arial, два веса: HUD 14 bold, hero 24 bold, значения плиток 16 bold, дата и названия 11–12 bold, дневник и подсказки 10, ячейка-флажок 14, 9 bold капс только для подписей секций; без rich text.

«Сделано»: одно правило на B5:I40, заливка + тёмно-зелёный глиф. «Сегодня»: янтарная дата, тёплая строка A:N; порядок правил «сделано → сегодня → будущее», зелёная плитка в строке «сегодня» остаётся зелёной. Серия: число, при ≥3 «🔥17» формулой; щит: 🛡 в списке привычек, пока пропусков в месяце нет. Достижения: чипы на «Годе», получено: 🏅 и акцент, нет: приглушённое «12/30», без замка.

## 5. Визуализации

Встроенных диаграмм ноль, включая «Год». SPARKLINE берут данные и опции только диапазонами; опции в «Списках» несут цвета темы; в Excel та же ячейка получает полосу данных и формат `;;;`.

- Полоса XP (A2:I2) и все полосы прогресса: одна формула `=IFERROR(SPARKLINE(Расчёт!AD10:AE10;Списки!$A$2:$B$5);"")`, AD:AE (пара «значение, остаток»), `Списки!A2:B5` = charttype|bar, max|1, color1|#22A35E (XP #8B5CF6), color2|#262B38.
- Столбики месяца, объединённая ячейка 64px: `=SPARKLINE(Расчёт!AF250:AF280;Списки!$A$8:$B$12)`.
- «Год»: карта 12×8, клетка 32×40px, доля 0–1 с форматом `;;;` и одной зелёной шкалой; справа полоса месяца (12 SPARKLINE); сверху три числа года, ниже уровень и десять чипов; ширина 360px.
- Батарейки и лента семи дней сняты; при провале SPARKLINE в объединённой ячейке строка 2 показывает XP текстом.

## 6. Механики в формулах

EL: прошедших дней месяца, DIM: дней в месяце, N: цель привычки, m: месяц, r: строка-день «Расчёта».

- Сегодня: `B1 =IF(ISNUMBER(Старт!$C$40);Старт!$C$40;TODAY())`; строка `C1 =IFERROR(MATCH(B1;A5:A370;0)+4;5)`; `D_r =A_r<=$B$1`.
- Честный прогресс: ожидаемо `=IF(N>0;N*EL/DIM;EL)`; привычка `=IF(EL=0;0;MIN(1;сделано/ожидаемо))`; месяц: сумма сделано / сумма ожидаемого.
- Пропуски месяца: `F_r =IF(B_r<>B_(r−1);0;F_(r−1))+IF(AND(D_r;NOT(отметка_r));1;0)`.
- Серия со щитом: `P_r =IF(отметка_r;P_(r−1)+1;IF(NOT(D_r);P_(r−1);IF(F_r<=бюджет;P_(r−1);0)))`; бюджет 1 для ежедневной (первый пропуск месяца прощён, второй рвёт), `MAX(1;DIM−N+1)` для цели N. Рекорд месяца `=SUMPRODUCT(MAX((B5:B370=m)*P5:P370))`; щит цел при F=0.
- День: `Z_r =COUNTIF(зеркало_r;TRUE)`; идеальный `AA_r =IF(AND(D_r;Z_r>0;Z_r=$B$2);1;0)`.
- XP дня: `AB_r =10*Z_r+20*AA_r+SUMPRODUCT(отметки_r*(2,5*(серии_r>=7)+2,5*(серии_r>=30)))`. Всего `=SUM(AB5:AB370)+50*целей+30*испытаний`. Уровень таблицей с порогами 50·n·(n+1): `=MATCH(XP;Списки!$F$2:$F$31;1)`.
- Достижения: десять, только на монотонных величинах (первая отметка, 100 и 1000 отметок, серия 7 и 30 по рекорду, 1 и 10 идеальных дней, уровень 5, 30 записей дневника, 3 цели). Чип `=IF(v>=цель;"🏅 "&имя;имя&" · "&v&"/"&цель)`, одно правило УФ на блок.
- Испытание недели, ротация четырёх: `k =MOD(INT((B1−DATE(год;1;1))/7);4)+1`; значения из блока 53 недель через SUMIFS/COUNTIFS по старту недели; текст, значение, цель: тремя CHOOSE(k;…); взято при значении ≥ цели, +30 XP.
- Бюджеты: ≤10 правил УФ на месяц (сделано, сегодня, будущее, выходной, тепло ×2, сон ≥7, цель выполнена, пустая дата), ≤130 на файл, ни одного с TODAY(), INDIRECT или ссылкой на другой лист; ≤15 SPARKLINE на лист; ≤12000 нелетучих формул, один TODAY(); пересчёт от галочки: цепочка ≤366 ячеек.
- Защита: IFERROR на каждой ссылке, `warningOnly` всего кроме ввода, «убрать привычку» = стереть название, числа только списками, строка самопроверки `=SUMPRODUCT(ISERROR(диапазоны)*1)` = 0.

## 7. План проверки

Смоук на Диске заказчика, пробник с одним месяцем: флажки после импорта; «Сегодня →» после «Создать копию» чужим аккаунтом; SPARKLINE с опциями диапазоном и в объединённой ячейке; формат `ddd d` в русской локали (запас `d`); защита и скрытые листы в копии; 2 ОС × 3 режима темы; промахи по 38px у трёх человек ≤1 на 24 тапа, иначе флаг 7×40; авиарежим.

Автоприёмка каждой сборки: матрица целей, тем, наборов данных и дат `--today`; ворота: линт формул и бюджетов, LibreOffice без ошибок кроме `sheets_only`, равенство `model.py`, импорт через API без errorValue и с BOOLEAN на сетке, PDF-рендер, round-trip diff.

Приёмка на телефоне (iPhone SE 375×667, Android 360×780, 100%):
1. Копия открывается на «Старте»; первая правка ≤3 тапа; восемь привычек ≤3 мин у трёх новичков.
2. Иконка → восьмая галочка ≤20 с, ≤11 тапов, ≤2 фликов, горизонтальный скролл 0; вечерний блок ≤10 с.
3. Цель касания ≥38×40px, отклик ≤300 мс, промахи ≤1 на 24.
4. Текст ≥10pt, ни одного «###»; закреплено ≤110px; ≥8 строк дней на первом экране.
5. Текущий месяц ≤1 свайп по вкладкам; имя вкладки ≤5 символов.
6. Ввод «abc» в формулу → предупреждение, ломается ≤1 ячейка; удаление строки дня: ноль #REF! вне неё.
7. Тёмная тема приложения на обеих ОС: контраст ≥4,5:1, состояния различимы без цвета.
8. Открытие ≤5 с тёплое / ≤8 с холодное; стресс-сборка без рывков; авиарежим работает.
9. Компьютер 1366×768: месяц и «Год» без горизонтального скролла, самопроверка = 0, печать: одна A4; Excel-бонус: та же геометрия, формулы ядра равны кроме швов, превью с цифрами.

## 8. Журнал споров отдела

1. **Ориентация сетки.** B4: недельные блоки «привычки строками»; остальные четверо: дни строками. Решил: дни строками, один флик до «сегодня», закреплённые иконки, сон и дневник в строке дня, лента «Расчёта» и есть дни строками. B4 уступил; имена закрыты иконками и списком под сеткой.
2. **Лента на год или двенадцать вкладок.** B3 (B4 с флагом): один видимый лист «Дни» на 366 строк с переходом по `#gid=&range=`; B1, B2, B5: двенадцать месяцев. Решил: двенадцать вкладок для ввода, лента B3: скрытый движок, серия через 31→1 и «удаление стоит день» сохраняются зеркалом, зависимость от непроверенной gid-ссылки исчезает, месяц — единица игры и родная навигация.
3. **Кодирование «сделано» и цвет.** B2: красить только флажок, янтарь только «сегодня», ноль красного; B1: заливка плитки, янтарь на прогрессе, розовые выходные; B3: только глиф, ведь Таблицы применяют первое сработавшее правило. Решил: заливка плюс тёмный глиф (двойное кодирование), янтарь только «сегодня», фиолетовый игре, красного нет; конфликт правил решён порядком: «сделано» первым.
4. **Закреплённая шапка.** B5: названия под 90° (178px); B2: ряд «батареек» (134px); B3: полоса XP 14px; B1: 8px, всего 104. Решил: 110px (HUD 40, XP 12, иконки 36, серии 22), потолок B5; батарейки отклонены, SPARKLINE в закреплённой зоне ≤1 (B4); 12px: середина между B3 и B1.
5. **Синтаксис SPARKLINE и политика формул.** B2: литералы массивов, OFFSET, ARRAYFORMULA для ленты семи дней; B3, B4: только диапазоны, ноль летучих; B5: счётчик формул как критерий (≤5000), B3 и B4: глубина пересчёта. Решил: только диапазоны, лента снята; критерий: глубина ≤366 ячеек и один TODAY(), потолок 12000 формул как страховка; 🔥 формулой, B1 уступил.

Также: восемь привычек (B3, B4), не десять «за сгибом» (B1, B5); счёт дня в HUD (B5); вечерний блок правее сетки (B2, B3; B5 уступил); доводка мастера через API (B4); год фиксирован при сборке: моё решение ради статичных строк недель.
