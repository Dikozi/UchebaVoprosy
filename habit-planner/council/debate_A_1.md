# Отдел A → отдел B · переговоры, раунд 1

Вводная сборки: Sheets API нет, только XlsxWriter → .xlsx → Диск → конвертация. Всё, что B отдал «доводке из Python через API» (локаль, часовой пояс, BOOLEAN-валидация, warningOnly, gid в «Списки»), делается в .xlsx или не делается; руки заказчика — одно действие в крайнем случае.

## 1. Беру у B без спора

- Структура: «Старт», «Янв»…«Дек» (три буквы, цвет по сезону), «Год»; скрытые «Расчёт» и «Списки». Свой «Обзор» снимаю: «Год» в 360 px и месяц без горизонтального скролла на компьютере закрывают бриф, 217 формул зеркала лишние.
- Движок «Расчёт»: лента 366 строк, зеркало отметок через IFERROR, серии со сквозным переходом 31→1, пропуски F:M, «удаление строки стоит один день», единственный TODAY() с переопределением со «Старта» и копией для УФ, бюджеты формул и правил, самопроверка SUMPRODUCT(ISERROR).
- Год фиксирован при сборке; годовое издание так и продаём.
- Вечер в строке дня за сгибом: списки по 56 px, дневник 190 px.
- Ноль встроенных диаграмм; SPARKLINE только диапазонами; полоса XP с текстовым запасным вариантом.
- Палитра и семантика: зелёный — сделано, янтарный — только «сегодня», фиолетовый — игра, красного и розового нет, пропуск — пустой квадрат, будущее «спит»; двойное кодирование заливка + глиф; порядок правил «сделано → сегодня → будущее».
- Типографика: Arial, два веса, флажок 14 pt, ничего мельче 10 pt.
- Чип награды «🏅 имя / имя · v/цель» на монотонных счётчиках: рекорд серии не откатывается, значит прогресс показываем у всех десяти — снимает возражение A2.
- Строка недели после воскресенья (20 px, приглушённая) как разделитель — при шрифте ≥10 pt.
- Excel-бонус адаптером, смоук и приёмка на телефоне; поправка: проверка импорта без API, глазами и по ячейке самопроверки.
- Поле «считать сегодняшним днём» — внизу «Старта».

## 2. Где не согласен

**Восемь привычек по 38 px.** Промах на 38 px — не «≤1 из 24», а тихая галочка в соседней привычке, которую никто не заметит (A3); 43–44 px — норма касания платформ. Семь — принцип, не пиксели: десять ежедневных привычек — «новая жизнь с понедельника» (A2), XP растёт с числом колонок и поощряет перегруз (A1), в посте «семь — столько, сколько держится» (A5). B сам держит флаг «7×40» — прошу сделать его основным.

**Шапка 110 px без строки дня и без имён.** Строка дня — единственный текст утреннего взгляда: «Вчера без «Дзен» · верни сегодня · рекорд 17» держит в точке срыва (A1, A2), в ней же события игры и счёт испытания (A4, A5). Семь пиктограмм без слов — ребус (A4): короткое имя до 6 знаков обязательно. Сводный 🔥 снимаю: у пятерых три определения серии, число двусмысленно; в рилсе растёт 🔥 над колонкой. «Сегодня 6/7» в HUD беру.

**Экономика.** +20 за «идеальный день» — премия за 100 %, убранная отделом единогласно: перфекционизм и «какого чёрта» после первого неидеального дня; слово «идеальный» под запретом, есть «полный день» — одноразовая награда. +50 за цель — XP за самоотчёт: цель закрывается галочкой, её начнут ставить ради очков (A2). +30 за испытание не виден на полосе. ×1,5 за первую галочку после пропуска обязателен — это механика «Возвращения», главной награды. Пороги 50·n·(n+1) дают 30 уровней и 30 имён; имён не будет: уровни числовые по 100·n·(n+1), второй на 4-й день, третий на 12-й, 13–15 в год, поверх — четыре звания (Разминка 1–3, Разгон 4–7, Ритм 8–11, Режим 12+).

**Испытание из четырёх готовых текстов.** «Лечь до 23:00» — не про этого человека (A1, A2, A4). Формула берёт слабейшую привычку прошлой недели и ставит «5 из 7»: семь COUNTIFS плюс MIN — дешевле блока на 53 недели.

**Воскресенья нет.** Вопрос «Что мешало — и когда и где сделаю иначе?» — единственная рефлексия с доказанным эффектом; без блока «Неделя» сон и настроение бросают на третий день, потому что плата за вечер — наблюдение о сне именно там (A2).

**Под сеткой — витрина v1.** Hero 83 % дублирует HUD; плитки «идеальных дней, серий, щитов» — те же KPI-плитки; три инсайта и средняя энергия — «по ним никто не действует». Оставляю список привычек с полным именем, «19/20 · 🔥17 · 🛡» и полосой: это наши «Итоги», только лучше.

**Тёмный файл плюс светлый второй.** Второй продаваемый файл удваивает поддержку (A5); тёмная тема приложения перекрашивает заливки — на тёмной базе результат непредсказуем, на светлой приложение само даёт тёмный вид (A3). Решает матрица B, критерий договариваем сейчас.

**«Цель дней в месяц».** Люди думают «раз в неделю» (A2); N = ROUND(f·DIM/7), формулы B не меняются. «Чтобы…» возвращаю: текст нужен строке дня после пропуска и блоку «Неделя».

## 3. Компромиссы

1. Шапка 138 px: HUD 36, SPARKLINE XP 12, строка дня 28, эмодзи с именем в одной ячейке 40 (14 pt над 10 pt), серии 22. XP текстом в HUD — 126.
2. Строки дней 44 px: цель 43×44, на первом экране ≥10 дней.
3. Без синеватой заливки прощённого пропуска (ей нужна ссылка на «Расчёт» в УФ): щит виден в строке серий «17🛡 → 17» и в строке дня.
4. Дата зеленеет только при 100 %; «теплеть при 50 %» снимаем — минус два правила, шкала одного тона.
5. Столбики месяца одной SPARKLINE — последней строкой блока «Неделя».
6. Испытание +100 вместо 150, если 150 ломает полосу; ниже 100 — нет.
7. ×1,5 с 30-го дня вместо 21-го — принимаю, если остаётся ×1,5 за возврат.
8. Тема: если в тёмной теме приложения хоть одно состояние (сегодня, сделано, будущее) неразличимо на любой ОС — продаём светлый файл, тёмный остаётся для рилса; проходит — продаём тёмный, светлый — непубликуемая копия для поддержки.
9. «Сегодня →»: без gid только HYPERLINK с Excel-адресом «#'Сен'!A25»; конвертируется — бонус, нет — ячейку убираем; главный путь — порядок строк и спящее будущее. Плитки месяцев на «Старте» — статические internal-ссылки, текущий подсвечен УФ.
10. Без API: чекбоксы только конвертацией булевых ячеек со списком TRUE,FALSE — ворота смоука; запасной путь — одно действие заказчика на мастере «выделить сетку → Вставка → Флажок»; warningOnly снимаем — IFERROR, скрытые листы, самопроверка.
